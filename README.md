# Sistema de Gestão Financeira 📊

Uma aplicação web responsiva para controle de finanças pessoais, projetada para uso independente em dispositivos móveis. O sistema permite o rastreio de despesas mensais, gestão de renda e painéis de controle, substituindo planilhas manuais por uma interface ágil e moderna.

## 🚀 Tecnologias Utilizadas

*   **Back-end:** Python, Flask
*   **Front-end:** HTML5, Tailwind CSS
*   **Banco de Dados:** SQLite (`financas.db`)
*   **Hospedagem:** PythonAnywhere

## 🛠️ Funcionalidades Principais

*   **Autenticação de Usuários:** Módulo seguro de login e recuperação de senha.
*   **Gestão de Perfil:** Centralização de configurações do usuário, incluindo o módulo de "Ajustar Renda".
*   **Dashboard Financeiro:** Visão clara de entradas e saídas.
*   **Design Responsivo:** UI/UX otimizada com Tailwind para navegação fluida no celular.

## ⚙️ Estrutura do Projeto

*   `/templates/` - Arquivos HTML da interface (base.html, perfil.html, etc.)
*   `/static/` - Arquivos estáticos (CSS, imagens, JS)
*   `financas.db` - Banco de dados local SQLite
