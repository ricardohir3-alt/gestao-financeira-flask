## 📌 Sobre o Projeto
Uma aplicação web completa para gestão financeira pessoal com um diferencial exclusivo: a **Jornada IA**. O sistema foge do modelo tradicional de planilhas chatas e utiliza gamificação e Inteligência Artificial (Google Gemini) para atuar como um mentor financeiro virtual (Mentor Hir3). 

A IA analisa o comportamento financeiro do usuário em tempo real, cruza com seus objetivos de longo prazo ("Caixinhas") e entrega conselhos dinâmicos e personalizados para manter o engajamento na economia mensal.

## ✨ Principais Funcionalidades

* **🤖 Mentor Hir3 (Integração com Gemini API):** Feedback dinâmico e gamificado gerado por IA com base no percentual de renda poupada e na meta ativa do usuário.
* **🎯 Caixinhas de Metas:** Definição de objetivos financeiros (ex: Reserva de Emergência) com cálculo automático da missão de poupança mensal.
* **📊 Dashboard Gerencial:** Resumo visual de entradas, saídas e saldo, com gráficos interativos utilizando ApexCharts.
* **🔮 Projeção de Gastos (Predição):** Cálculo inteligente que projeta como o saldo terminará o mês com base no ritmo de gastos diários.
* **🔔 Sistema de Alertas Inteligentes:** Notificações flutuantes para contas que vencem hoje, amanhã ou que estão atrasadas.
* **🌓 UI/UX Moderna:** Interface 100% responsiva construída com Tailwind CSS, incluindo suporte nativo a Modo Claro e Modo Escuro, além de proteção de privacidade (ocultar valores).
* **⚙️ Banco de Dados Autogerenciável:** Estrutura em SQLite com função de inicialização automática (`iniciar_banco`), facilitando o deploy em novos ambientes.

## 🛠️ Tecnologias Utilizadas

* **Back-end:** Python, Flask
* **Front-end:** HTML5, Tailwind CSS, JavaScript (Vanilla), ApexCharts, Lucide Icons
* **Banco de Dados:** SQLite3
* **Inteligência Artificial:** API do Google Gemini
* **Deploy/Ambiente:** Compatível com PythonAnywhere e servidores Linux/Windows.
